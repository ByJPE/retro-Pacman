# Retro Pacman

Jeu de labyrinthe type Pac-Man en un seul fichier HTML, jouable sur ordinateur et smartphone.

## Fonctionnalités
- 3 niveaux de difficulté : Facile, Normal, Difficile
- Mode 1 : style années 70, monochrome bleu, scanlines, sons carrés
- Mode 2 : style années 80, néon couleur, scanlines, sons synthétiques
- Sons générés par Web Audio (aucun fichier audio)
- Aucune dépendance (hors police Google Fonts « Press Start 2P », avec repli système)

## Contrôles
- Ordinateur : flèches du clavier, Échap pour revenir au menu
- Smartphone : glisser le doigt dans la direction voulue
